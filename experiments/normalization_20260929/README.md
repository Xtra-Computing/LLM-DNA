# 缓存 normalization 消融与原实验复现（2026-09-29）

本次离线实验恢复了全部 **313 个原保存 DNA 向量**，并重现论文 Table 1 的 Qwen 关系预测结果。第一步回答嵌入取前 64 维后做 L2 normalization，才与原保存向量一致。去掉这一步后，多投影种子的平均关系预测表现与保留它基本相当，**没有足够证据说明 normalization 有稳定收益或稳定损害**。

按运行前固定的验证集选择规则，`none` 被选为暂定默认（`normalize_embeddings=False`）。必须同时说明：严格按模型对分组并去重后，两种设置的验证 F1 都为 0，选择仅由次要的 AUC 打破平局，证据很弱。需要复现原保存结果时，应显式设 `normalize_embeddings=True, random_seed=42`。

## 实际比较了什么

固定回答、编码器、600 个探针及顺序、前 64 维、128 维输出和随机投影矩阵，只改变以下步骤：

```text
none: Qwen 回答嵌入[4096] → 前64维 → 保留600槽位并拼接[38400] → 共享随机矩阵[38400,128]
l2:   Qwen 回答嵌入[4096] → 前64维 → 每条回答L2归一化 → 相同拼接和相同共享矩阵
```

- 编码器为 `Qwen/Qwen3-Embedding-8B`，不是另一个编码器。缓存中的 `dim1024` 文件是 BGE 嵌入，不能与 Qwen 混为同一消融。
- 原始 4096 维 Qwen 缓存已经是单位范数，观测范围为 0.99999982–1.00000012。这次关闭的是**取前 64 维之后追加的归一化**，并没有移除编码器内部的归一化。切片后范数为 0.03810–0.20643。
- 空回答对应全零槽位，600 个槽位固定。未丢弃探针，也没有 max pooling、逐模型拟合 StandardScaler 或拼接后截断。
- 投影使用原实现的 MT19937 正态随机矩阵、float32、按列归一化；不是 sklearn GaussianRandomProjection 的缩放实现。投影种子为 `0,1,2,3,4,42`，两组共享同种子的矩阵。
- 关系分类器仍使用训练集上拟合的 `StandardScaler + SVC(RBF, probability=True, class_weight="balanced")`。这个下游分类步骤与 DNA 提取前的 normalization 是两件事。

输入为私有仓库本地副本 `/home/zhaomin/project/dna`，提交 `6e38570ad79989e7b591431c61ec73bf7ce2d094`；缓存真实路径为 `/ssd3/zhaomin/dna/cache`。345 个回答文件中，316 个有完全匹配的有序 Qwen 缓存，29 个被明确排除；其中 313 个有可比较的历史 DNA。每个模型均核对全部有序 prompt 和非空回答，不仅依赖历史缓存的 `MD5(sorted(texts))` 文件名。重复缓存的编码数值一致。没有生成新回答、调用模型 API、修改输入缓存或 push。

## 论文关系预测指标

原评估器分别读取 5 份 `valid_llm_relation_enriched_seed*.csv`，对每份文件按分割种子 `0..4` 做分层 80/20 划分，共 25 次。每个模型对的分类特征为 `concat(abs(dna_a-dna_b), dna_a-dna_b)`。表中的 ± 为这 25 次的样本标准差。

**复现论文 Table 1 必须使用与 PhyloLM 都有结果的共同 43 模型集合**，5 个数据文件分别保留 144、149、146、141、147 行。直接使用全部 47 个 DNA 模型会得到另一个分数，不能把集合差异误判为提取实现问题。

| 共同43模型，投影seed42 | Accuracy | Precision | Recall | F1 | AUC |
|---|---:|---:|---:|---:|---:|
| 原保存DNA | .918805 ± .048170 | .898107 ± .049223 | .956500 ± .071768 | .924673 ± .046996 | .979213 ± .026640 |
| 重建：追加L2 | .918805 ± .048170 | .898107 ± .049223 | .956500 ± .071768 | .924673 ± .046996 | .979213 ± .026640 |
| 消融：不追加L2 | .909241 ± .052895 | .883309 ± .054265 | .956500 ± .071768 | .916888 ± .050210 | .976357 ± .032192 |

重建结果按论文三位小数显示为 Accuracy **.919 ± .048**、F1 **.925 ± .047**、AUC **.979 ± .027**，与原评估器读取保存 DNA 的结果相同。此处复现的是关系预测和保存向量，不代表重新跑完所有论文实验。

作为集合敏感性检查，全部 47 个模型、每份166行的 seed42 结果为：L2 F1 .866612、AUC .920692；不追加 L2 F1 .867014、AUC .918062。L2 重建仍与原保存 DNA 的指标完全一致。

## 去重、分组验证与默认设置的证据边界

历史关系数据存在同一模型对的多个关系来源（如 `tags`、`cardData`），原评估器以关系三元组为行划分，训练/测试之间每次有 **10–15 个相同无序模型对**。因此原论文协议的高分不能直接解释为“对从未见过的模型对的泛化”。这里忠实重现原协议，并单独报告更严格的敏感性检查，没有悄悄修改原论文比较标准。

新选择协议先合并5份数据、去除同一有序模型对的关系来源重复，得到 **417 个有序模型对，只有29个正例，376个无序分组**。正反方向放进同一组；有8组正反方向标签不同，保留有序标签而不擅自修正。固定种子1729分出20%分组作为留出集；剩余分组按5个种子分别划分75%训练、25%验证。每组 normalization 使用相同划分，投影6种子 × 验证5划分共30次；按平均验证F1、然后AUC、最后none的规则选择。选择结果先写入 `selection.json`，再计算留出指标。

| 检查 | L2 F1 | none F1 | L2 AUC | none AUC |
|---|---:|---:|---:|---:|
| 分组验证平均 | 0 | 0 | .481917 | .498831 |
| 固定留出集平均 | 0 | 0 | .398268 | .411616 |

两组均没有正确识别出正例，验证F1没有区分力；AUC也不足以支持可靠排序。留出集仅83行、6个正例。这些数据已经用于原论文协议，模型本身也跨组出现，**不能把该留出结果当作独立新数据或模型互斥的泛化评估**。本检查说明原数据重复结构会显著影响结论；它同时去重、改变正负比例并按组分割，不能把分数下降全部归因于某一个因素。

当前默认 `normalize_embeddings=False` 是依照预先固定的次要指标规则选择的**暂定设置**，也符合论文未额外写出这一步的公式。它不是已经验证优于L2的设置。原实验数值复现仍须显式打开L2。
